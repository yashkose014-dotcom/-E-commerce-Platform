# 🛒 Urban Mart

A modern **full-stack e-commerce platform** built for a smooth, secure, and responsive online shopping experience.

## 🚀 Features

- 🛍️ Product browsing and search
- 🔎 Category and product filtering
- 🛒 Shopping cart
- ❤️ Wishlist
- 👤 User registration and login
- 📦 Order management
- 💳 Checkout and payment-ready architecture
- 🎟️ Coupon support
- ⭐ Product reviews and ratings
- 🛠️ Admin dashboard
- 🌙 Dark & ☀️ Light mode
- 📱 Fully responsive design

## 🛠️ Tech Stack

**Frontend**
- React.js
- Vite
- Tailwind CSS
- React Router

**Backend**
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone <your-repository-url>
cd Urban-Mart
```

### 2. Start Backend

```bash
cd backend
npm install
npm run dev
```

### 3. Start Frontend

Open another terminal:

```bash
cd frontend
npm install
npm run dev
```

Then open the URL shown by Vite in your browser.

## 🔐 Environment Variables

Create `.env` files using the provided `.env.example` files.

Example:

```env
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
PORT=5000
```
